Do not overclaim

Where 4.6 still loses

A dashboard that only shows wins is a press release. These are the rows that should change how you route work.

  • Not #1. Opus 5 max/xhigh 63, Fable 62, then the 61-tie. “World’s third-best” is a collapsed headline — don’t use it.
  • Long-horizon repos. SWE-Marathon 31.9% vs Opus 5 50%. Terminal-Bench v3.0 26% vs 43.5% / 34.6%.
  • DeepSWE v1.1 65.9% vs Opus 74% and Sol 73% (vendor-compiled peers).
  • 500k context vs 1M on Opus, Sol, Gemini, Kimi. Same window as 4.5 — this was not a context release.
  • Cache is dearer than 4.5 ($0.50 vs $0.30). Cost per AA task rose $0.36 → $0.84 because the smarter traces spend more.
  • Consumer Grok/X later. Ships in Cursor, Grok Build, API, and partners today.
