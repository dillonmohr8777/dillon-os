# BigOrange Marketing Client Intelligence Overlay

## Executive operating thesis

BigOrange already has mature WordPress production and marketing capabilities.
The highest-value contribution is a governed operating system that connects
research, Semrush and first-party evidence, high-craft page production,
technical QA, AEO/GEO, analytics, and human review—without mistaking public
technology detection for authenticated access or client performance.

## Current evidence snapshot

- The relationship advanced from interview into a focused web-development and
  process review.
- Public evidence identifies WordPress, Elementor, Yoast, WP Rocket, Cloudflare,
  Wordfence, accessibility tooling, and Semrush integration routes.
- Capability-showcase and growth-dashboard artifacts exist.
- No private WordPress, Semrush, analytics, CRM, query, lead, ranking, or revenue
  data has been mapped into this evidence layer.

## Pilot: custom-home-builder pillar

The pilot should begin with client reality and first-party evidence, then combine
query research, customer language, competitive/source analysis, intent
clustering, page decisions, answer-ready structure, original proof, internal
links, schema parity, conversion instrumentation, visual QA, and measured
outcomes. It should produce a reusable workflow card, not only an audit.

## Next evidence sprint

1. Confirm the exact role, client/project boundary, reviewer, and production
   access path.
2. Capture a dated read-only search, content, technical, and analytics baseline
   for the selected pillar.
3. Build the topic-to-page-to-proof-to-conversion map.
4. Produce one reviewable high-craft page or cluster and run deterministic plus
   human QA.
5. Record time saved, defects found, visibility change, qualified outcomes, and
   reusable process improvements.
