# Mohr Media Website

A full multi-page marketing site with an immersive WebGL look modeled on Active
Theory. No build step, no framework — plain HTML + shared assets + raw WebGL, no
external libraries or CDNs. Drop the folder on any static host and it runs.

## Pages (20)
- `index.html` — home: hero, proof strip, 3D robot roster, services, method, results, operator, pricing, FAQ.
- `services.html` — the five systems + the Mohr Method.
- `work.html` — four case studies (challenge → approach → result).
- `agents.html` + `agent-*.html` — the roster index and **one page per agent** (8), each with its own big 3D robot and accent.
- `about.html` — the operator bio (Dillon), the eight-agent model, doctrine, and a family band.
- `pricing.html` — Audit / Build / Operate + comparison, guarantee, FAQ.
- `blog.html` + `blog-*.html` — insights index and **four full posts** (lead-gen systems, AEO/GEO, the $497 audit, local Google Ads).
- `contact.html` — book-the-audit page + qualifying form (composes a mailto on submit).

## Shared assets (`assets/`, cached across pages)
- `site.css` — the whole design system incl. embedded fonts (base64).
- `spine.js` — the WebGL "spine" background; each page sets its waypoints via `window.__SPINE = { anchors, wpts }`.
- `robot.js` — the 3D robot crew (home, agents index, and each agent page). A slot can force its accent with `data-acc="r,g,b"` (0–1 floats).

## SEO / AEO / GEO
- **JSON-LD** on every page: `Organization`/`ProfessionalService` + `WebSite` + `Person` (founder) sitewide, plus `Service`, `BlogPosting`, `FAQPage`, `BreadcrumbList`, and `ItemList` where relevant.
- **`robots.txt`** explicitly allows AI answer-engine crawlers (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, etc.) and points to the sitemap.
- **`sitemap.xml`** lists all 20 URLs.
- Per-page canonical, Open Graph + Twitter cards, `og.png` (1200×630) + `logo.png` (512×512) + `favicon.svg`.
- AEO patterns baked into content: TL;DR blocks, question-style H2s, FAQ sections (matched by `FAQPage` schema), consistent entity facts.

## Swappable photos
- `operator.jpg` — Dillon's headshot (home + about). Replace the file to update.
- `family.jpg` — the family photo on the About page. Drop a ~3:2 image in as `mohr-media-site/family.jpg`; until then the frame shows a "DM" placeholder. No code change needed.

## Deploy
This Vercel project deploys via the CLI (no linked git repo):
```
cd mohr-media-site && vercel deploy --prod
```
Or point any static host at the folder. Nothing to compile.

## Regenerating
The pages are generated by scripts kept in the session scratchpad (`build2.py` for
the core pages, `build3.py` for agent/blog/bio pages + SEO infra, reading
`blogs.json`). Edit the generated HTML directly for one-off changes.
