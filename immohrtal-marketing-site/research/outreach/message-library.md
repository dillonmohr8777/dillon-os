# IMMOHRTAL outreach message library

Status: **DRAFTS ONLY. NO MESSAGES SENT.**

## Draft rules

- Replace every bracketed field with a verified fact or remove the sentence.
- Never write “I noticed” unless the observation was reproduced from a current public source.
- Keep the first touch in plain text, under 150 words, with one link and one ask.
- Do not add a calendar link to the first touch.
- Do not mention a client, result, metric, testimonial, ranking, or AI citation unless it has separate public approval and current evidence.
- Add the approved sender identity, physical mailing address, and opt-out language only after they are verified.
- Suggested compliance line: `If you would rather not hear from me, reply no thanks and I will close the loop.`

## Optional follow-up angles

These are angle prompts, not permission to start a sequence.

| Touch | New value | Suitable page |
|---|---|---|
| Follow-up 1 | A second, adjacent observation that changes the diagnosis | Relevant service page |
| Follow-up 2 | A guide that helps the prospect evaluate the problem without buying anything | Relevant insight page from `page-routing-map.md` |
| Follow-up 3 | One direct question about priority or timing | No link |
| Follow-up 4 | Ask whether another role owns the issue | No link |
| Final | Close the loop professionally and preserve the opt-out | No link |

Never send “just checking in,” repeat the original message, or invent urgency.
