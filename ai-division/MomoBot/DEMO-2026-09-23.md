## Chapters

1. **Front door** (0:00–1:04) — The scrapbook collage with Momo pinned up
   front, the "ground rules" hello (agents, runs, receipts, memory), and
   invite-only sign-in.
2. **Choosing how you work** (1:05–1:49) — First sign-in asks Easy, Medium,
   or Hard as a guidance level; changeable anytime.
3. **Easy mode** (1:49–6:19) — Plain-words chat with a South Philly bakery
   example. Momo drafts a caption + hashtags, asks follow-up questions
   (name, hours, location) to "remember" the client, then tightens copy
   using that context. Helper chips offer plain-language next steps.
4. **Mission Control** (6:19–7:33) — The agent-team dashboard: Dillon Brain
   leading specialists, run/error/token counts, Agent Studio, Jobs
   (execution history), Workflows (scheduling).
5. **Hard mode** (7:33–13:03) — Model/effort picked manually; a dental-client
   local SEO/GEO brief. Momo pauses for a structured intake (business name,
   address, services, target date, current assets) before running, showing
   token use and reasoning depth live.
6. **The Momo crew** (13:03–14:09) — Specialist agents (Analytics Engineer,
   Data Migration Engineer, Dillon Brain, etc.), each with its own job and
   guardrails.
7. **Capabilities** (14:09–15:10) — Capability Center: office/knowledge
   connections (Notion, research tools, HubSpot, GitHub, custom plugins).
8. **Scheduled tasks** (15:10–15:53) — Recurring prompts, e.g. a Monday
   client report that runs itself.
9. **The Momo Daily** (15:53–16:58) — A daily scheduled task that produces
   an AI-written "newspaper" edition; Momos draft, a person approves before
   the team/clients see it.
10. **Appearance** (16:58–22:30) — Four themes (Paper, Space, Future, Retro
    16-bit) over the same layout; Paper is the default for client-facing
    review.
11. **Wrap-up** (22:30–25:56) — Recap via a live Greenline Fitness example:
    Mission Control as the single pane of glass, what's next (more client
    spaces, agent voice/quality tuning).
