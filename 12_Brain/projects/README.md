# Projects

**Summary:** the one home for active delivery threads and goals, whether a human
or an automation run wrote the note.

Use [[12_Brain/templates/Project|Project template]]. View in
[[12_Brain/bases/Projects.base|Projects.base]], which filters on `status` and
excludes `Experiments/` — a proposal is not a delivery thread.

## Experiments

Proposals awaiting a maker/checker pass, written by the intelligence stack into
`projects/Experiments/` and viewed in
[[12_Brain/bases/Experiment Queue.base|Experiment Queue.base]]. That Base filters
on `experiment_stage` and `status`, so a proposal missing those properties will
not appear in it.
