# Captures

Immutable receipts: articles, transcripts, meeting source material, exported
threads, screenshots with extracted text, and research evidence.

- Add new captures; do not rewrite existing captures.
- Filename: `YYYY-MM-DD - short source title.md`.
- Include source, capture time, and provenance.
- Mark `status: compiled` only after durable facts and lessons have been
  reflected in canonical notes.
- Redact secrets and unnecessary personal data before saving.
