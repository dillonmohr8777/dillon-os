# concepts/ — one page per idea

A concept is an idea worth keeping: a strategy, a pattern, a lesson learned.
One lesson per file, one-line summary at the top, `source:` link back to where
it came from. Update the existing page instead of duplicating; delete pages
that turn out to be wrong.

Same frontmatter format as `entities/` (tags, source, updated). Research
findings additionally carry an `expires:` date.
