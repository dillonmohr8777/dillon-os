# Claude in Chrome

Official extension letting a **local** Claude Code session drive Dillon's real
Chrome — logged-in sessions intact (Google Ads MCC, Gmail, GBP), visible in
real time, pauses on logins/CAPTCHAs for manual handling. The successor to the
old Codex "Chrome-attachment" pattern.

- Setup: install "Claude in Chrome" extension (Chrome/Edge only) → `claude --chrome`
  from `~/dillon-os` (or `/chrome` in-session). Pro/Max/Team plans.
- **Does not work from Claude Code on the web** (cloud sandbox = headless
  Chromium only, no user sessions).
- Division of labor: remote sessions prep campaign packets + compile the vault;
  local `--chrome` sessions do hands-on-glass Ads publishing/optimization with
  Dillon watching — the [[12_Brain/concepts/Draft-First Operating Rules|draft-first]]
  gate embodied.
- Launch from inside the vault repo so the session loads CLAUDE.md + client
  pages (policy history, tracking setups) before touching campaigns.
