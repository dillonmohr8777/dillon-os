# Seedance 2.5

**Summary:** ByteDance one-take audio-video model — draft 30s ads and
outreach clips here; live Higgsfield output is 720p, not 4K.

Official homepage: https://seed.bytedance.com/en/seedance2_5
Launch post (2026-07-31):
https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5

Official refs in one pass: up to 30 images + 10 videos + 10 audio.
Official duration: 30s one-take plus multi-round extension. Official
access named on launch: Jimeng AI, Doubao Pro; BytePlus ModelArk API
was "coming soon."

Higgsfield (third-party, catalog pull 2026-08-07) ships
`seedance_2_5` with modes `t2v`, `omni_reference`, `video_edit`,
`video_extension`. Live resolution enum is 480p/720p. `generate_audio`
defaults true. No start/end-frame on 2.5.

This Cursor session's Higgsfield MCP is `needsAuth`. Connecting it
and spending credits are operator actions.
