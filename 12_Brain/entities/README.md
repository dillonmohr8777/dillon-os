# entities/ — one page per concrete thing

An entity is a concrete noun the business touches: an organization, a person,
a tool, a competitor, a platform. One page each, compiled by the agent from
`12_Brain/raw/` and the working folders.

Seeded here: [[12_Brain/entities/Marketing Chief Operator|Marketing Chief Operator]].

**Exception:** clients and the employer already live in `01_Clients/` with an
established format the daily skills depend on. Those pages stay there — link to
them with `[[wikilinks]]`, never duplicate them here.

## Page format

```markdown
---
tags: [entity, <kind>]
source: [[raw file or vault note it was compiled from]]
updated: YYYY-MM-DD
---
# Name
One-line summary.

(facts, each traceable to a source)

## Links
- related [[pages]]
```
