# Context Economy

**Summary:** the context window is an expensive room — everything that enters
is paid for in tokens, so the vault is read by trail, not by sweep.

Rules:

1. `CLAUDE.md` is the always-paid tax: it loads every session, so it stays
   under 200 lines and points at the vault instead of containing it.
2. Everything else is pay-per-read: start at [[INDEX]], grep for keywords,
   follow [[wikilinks]], open only the pages the trail points at. A
   full-folder sweep is the one move that never happens.
3. Big cross-vault questions go to a subagent: it reads fifty pages in its own
   separate context and returns one paragraph of conclusions. The expensive
   room holds decisions, not the library.
4. Model routing follows the same logic: nightly compile and routine updates
   run on the cheap tier; only the weekly synthesis pass earns the premium
   model. Routing routine work to the big model burns money for nothing.
