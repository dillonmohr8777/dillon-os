# CMO Lane Cost Discipline

**Summary:** Default CMO work to `balanced`, run four earning agents, and never
report simulated GEO.

Connect the expensive profile only after a real seed proves the output is
worth sending. Judgement, strategy, and reconciliation stay on the strong
model; everything else downshifts. Sixteen daily agents are a cost and queue
problem, not a quality strategy.

Paid search, local/GBP, technical SEO, and attribution reconciliation are the
lanes that earn. Content/social composition can be bought. GEO numbers from a
simulator are a demo, not a client metric, even if they run at premium rates.

## Limits

- Dollar-per-client figures in the source capture are briefing estimates, not
  a live ledger.
- This lesson does not authorize API spend, publisher writes, or a Netlify
  production publish.
- Dillon OS's seven operating agents are a separate roster; do not disable
  them because the CMO lane is four-wide.
