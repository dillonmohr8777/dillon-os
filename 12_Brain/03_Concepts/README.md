# Concepts

One reusable lesson or mental model per note. Concepts explain what the system
has learned, link to evidence, identify limits, and change when better evidence
arrives.

## Strategy library

![[../Bases/Strategy Library.base#Strategy Library]]

The strategy layer is the compiled operating knowledge of Dillon OS. It turns
research, campaign evidence, client work, automations, experiments, and reviews
into reusable systems rather than leaving the learning trapped in source notes.

## Operating rules

1. Preserve raw evidence in its canonical source location.
2. Compile durable lessons here with `source_refs`, limits, failure modes, and a
   review date.
3. Link every system to adjacent systems and the templates that put it to work.
4. Update the canonical concept when evidence changes; do not create a competing
   version of the same mental model.
5. Run [[../09_Ops/Knowledge Coverage|Knowledge Coverage]] after material changes.
