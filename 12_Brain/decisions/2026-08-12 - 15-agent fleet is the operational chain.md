# 15-agent fleet is the operational chain

**Decision:** Complete the managed-agent link chain as 15 named agents (7 vault lanes + 8 Mohr Media roster names), add nine surface agents for W2/book/artist/product/CRM/intel/compliance/brain/comms, and map 54 proven routines plus 22 readable codebases onto that graph. Do not mint one agent per routine.

**Why:** The 64GB orchestrator spec already named seven vault agents; Mohr Media already ships an eight-agent roster. Together they are the 15-agent chain. Routines stay skills and automations. Agents orchestrate them. GitHub search proved 16 public repos; six in-vault products make 22 surfaces this environment can actually read.

**Implications:**

- New work routes through [[11_Agents/Fleet Roster|Fleet Roster]] callsigns.
- Cursor custom agents in `.cursor/agents/` invoke the vault defs.
- Generic `cs-*` agents in claude-skills-repo stay a template library, not this OS's chain.
- Align HCM remains a surface agent with a hard wall against Momentum 360 client routing.
