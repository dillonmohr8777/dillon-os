# Fable 5.1 launch signal sweep

**Summary:** Fable 5.1 is a cost-shape change, not a design-quality leap. The
verified lever is effort level and skills, not the model tier. Higgsfield MCP is the
recurring video stack but is uninstalled, unsubscribed, and every call is spend.

## Findings (sourced) vs anecdotes

| Claim | Strength | Evidence |
|---|---|---|
| Cache reads drop to $0.25/M; input and output prices unchanged vs Fable 5 | Verified | Anthropic overview doc |
| Anthropic itself says start with Opus 5 and escalate only when it falls short | Verified | Overview doc; AI_masaou confirms from usage |
| Effort is the primary cost lever; medium ≈ Fable 5 quality | Verified | Prompting doc; AI_masaou (~25k vs ~200k tokens) |
| Skills matter more than model tier for frontend output | Strong anecdote | AdamHoltererer side-by-side; JustinGorya medium+skills; moderncreator pipeline |
| Fable 5.1 frontend is mixed: better animation consistency, but two credible "regression / no leap" reports | Contested | daradoescode, ivanjurashere vs KairollaAdil, loktar00 |
| Sol is ~6x cheaper on mechanical three.js builds, Fable more detailed | One datapoint | aimlapi head-to-head |
| CLAUDE.md prose does not reliably stop Fable subagent spawning; settings-level pin does | Strong anecdote + feature | chadbartels; Bell_QuoLu on CC 2.1.257 |
| Subscription quota is dominated by cache-read volume from long fat sessions | One datapoint | spacepope 86.9M cache reads |
| Claude + Higgsfield MCP is the dominant public AI-ad and scroll-hero stack | Pattern (6 of 13 lane A/B posts) | hikarun, igor_fedorko, KDickson, dravenip, JiEnoch, prompt_soru |

## What this changes for Dillon OS

1. **Do not move the default model to Fable 5.1.** Keep Opus 5 (or Codex/Sol) as the
   worker default. Reserve Fable 5.1 at medium effort for the design-authority pass
   in [[12_Brain/02_Entities/Website Factory|Website Factory]] and for synthesis
   loops that already earn the premium tier (`/synthesize`).
2. **Pin subagents to a cheap model in settings**, not in prose. The dillon-os agents
   in `.claude/agents/` should carry an explicit cheap model where the harness allows
   it. This is the fix for the chadbartels failure.
3. **Add two lines to CLAUDE.md** from the prompting doc: keep changes to what the
   task asks, and surgically edit rather than rewrite. Both cut output tokens.
4. **Shorten sessions.** The 3.5 hour redesign session and the 86.9M cache-read
   ledger are the same failure. Batch work into skills (`/site-factory`,
   `/mirror-and-improve`), not conversations.
5. **Scroll-hero video** already exists as a public recipe (Claude Code + Higgsfield
   hero clip + Hostinger). Dillon OS has the site half; the video half is the gap.
   Cheapest bridge is the connected HeyGen HyperFrames MCP for code-driven motion,
   which costs no new subscription. Higgsfield only when a client pays for footage.
6. **Reference-driven generation** (paste a competitor video or a Pinterest image)
   is the same shape as `/mirror-and-improve`. Worth one experiment on a Momentum
   real-estate prospect, staged 480p then 1080p.
