# Variant

**Summary:** generative UI feed at `https://variant.com`. Enter a short idea,
scroll design cards, optionally restyle with an eyedropper. HTML or React
export is claimed by third-party listings and is not live-verified without an
account.

## What it is

- Product promise: endless designs for an app or site idea, no canvas and no
  prompt-engineering loop.
- Public homepage already shows sample cards. Prompting, Surprise me,
  `/community`, `/explore`, `/gallery`, and `/pricing` all open a sign-in wall
  (Google or email).
- Adjacent tools in this vault: [[12_Brain/02_Entities/LandingFolio MCP]] is
  layout reference; [[12_Brain/02_Entities/Website Factory]] is the production
  pipeline. Variant is neither.

## Verified on 2026-08-18

- Homepage loads without auth and lazy-loads sample UI cards.
- Custom generation from the public prompt box is gated.
- No public HTML or React export control was visible on the unauthenticated
  homepage cards.
