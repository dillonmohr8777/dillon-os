# Guest Post Pipeline

## Layer 2 targets
- **CrimeReads** — literary crime fiction vertical. High editorial quality. Pitch essays that hook on novel themes without being overtly promotional.
- **Spybrary** — spy fiction community. Podcast / blog. Approach with angle-specific pitches about the CIA operative layer.
- **Independent Book Review** — debut-novelist coverage. Review request + essay submissions.

## Process
1. Pitch → acceptance → draft → publication.
2. Each published piece links back to ironicineptocracy.com lead magnet.
3. Log published date, outlet, backlink URL, and referral traffic in this file.
