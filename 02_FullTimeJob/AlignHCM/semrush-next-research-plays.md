## Semrush reports you may never have run (do these)

1. **Keyword Gap** (Organic)  
   Align vs `outsail.co` + `predictivehr.com` + `emphasishr.com` + `hrchitect.com`.  
   Filters: Position = Missing / Untapped; Volume ≥ 50; KD ≤ 40; include words: dayforce, ukg, hcm, implementation, partner, managed, payroll.  
   Export → this becomes the real competitor hit list.

2. **Keyword Gap → Weak**  
   Same domains, Weak filter (they rank better than you on shared terms).  
   These are “outrank them” pages — update content + internal links, don’t rewrite from scratch.

3. **Organic Research → Pages** (competitors)  
   Sort competitor pages by traffic. Steal *page types* (not copy): partner pages, industry hubs, comparison posts, calculators.

4. **Position Tracking project**  
   Folder: Align Money Terms. Add:  
   - all P1 missing gaps  
   - all Align page-1 terms to protect  
   - 20 competitor brand+service hybrids (e.g. “outsail dayforce”, skip; prefer category terms)  
   Weekly email. This is how you know you’re winning.

5. **Topic Research / Content Toolkit** on hubs  
   Seeds: `hcm managed services`, `dayforce implementation`, `ukg implementation partner`, `healthcare payroll`, `government payroll`.  
   Build cluster maps for SmartCare + industry pages.

6. **Phrase Questions** (API or UI) per money page  
   FAQ blocks + AEO. You barely have question coverage on Dayforce/public sector yet.

7. **SERP Features / AI Visibility** (if plan includes)  
   Track whether Align is cited for “best dayforce implementation partner mid-market” style prompts. Manual fallback: 25 prompts/month in ChatGPT + Perplexity.

8. **Backlink Gap**  
   Align vs OutSail / Emphasis / Ascend. Target partner directories, UKG/Dayforce partner pages, HR pubs, local chambers for public sector.

9. **Organic Research → Subdomains / Competitors → PLA / Paid** (light)  
   See if competitors buy `ukg implementation partner` / `dayforce consulting` — if CPC is high and you rank organic #2–7, protect those URLs hard.

10. **Site Audit + On-Page** on money URLs only  
    `/partners/ukg`, `/dayforce-implementation`, `/services/support`, `/services/integration`, industry pages.  
    Fix cannibalization (multiple URLs ranking for same UKG terms).

11. **Cannibalization report**  
    Filter Align organic for duplicate intents (`ukg pro implementation*`, `ukg implementation*`). One URL owns each intent.

12. **Brand vs Non-brand split** in Organic  
    Align’s traffic is heavily branded (`align hcm`). Non-brand growth = the gap list. Report non-brand weekly so leadership sees real SEO progress.
