# LinkedIn Post: 6 Things Before Payroll Implementation

**Author:** Maher (CEO) | **Target:** HR Leadership, CHROs, Finance Leaders, Operations | **Format:** Static graphic (1200 x 627, approved blog card) + link to blog

## Post copy

A payroll implementation rarely fails at go-live. It fails months earlier, in the decisions that get skipped before kickoff. I've watched organizations breeze through in a few months with barely a hiccup, and I've watched projects burn budgets and goodwill for over a year. The difference was never the platform. It was how prepared the team was before anyone configured a single thing.

In my latest piece, I share the six things I tell every business before their payroll implementation starts: documenting the current state nobody wrote down, the data migration everyone underestimates, and the post-go-live support that should be planned before day one. Give it a read before you commit to an implementation timeline, and you'll walk into kickoff ahead of most teams.

Read it here: https://www.alignhcm.com/blog/6-things-before-payroll-implementation
