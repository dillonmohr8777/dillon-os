# Brain Review

1. Read the latest seven days of changes, current operating status, active
   projects, decisions due for review, expiring research, and memory due for
   review.
2. Run `System/scripts/Update-SecondBrainHealth.ps1`.
3. Write a dated note in `12_Brain/07_Reviews/`.
4. Report wins, drift, contradictions, open loops, and the three highest-value
   next moves.
5. Link every conclusion to its supporting note.
6. Do not send, publish, spend, or mutate external accounts.
