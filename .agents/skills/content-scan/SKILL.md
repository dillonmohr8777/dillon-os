# Content Scan

Audit the content pipeline. Work only from this vault.

1. Read everything in `03_Content/` (hook libraries, ad copy, keyword targets,
   blog opportunities) and active items in `02_Campaigns/`.
2. Classify each piece: **ship-ready**, **needs one pass**, **raw idea**.
3. Cross-reference `SEO/` keyword targets against existing drafts to find gaps.

Write `Daily-Briefs/content-scan-YYYY-MM-DD.md` (today's date):

- **Ship this week** — up to 5 pieces, ranked, with the single edit each needs
- **Best raw ideas** — 3 worth developing, with the angle
- **Gaps** — keyword or campaign targets with no draft behind them
- **Kill list** — stale drafts to archive

Be opinionated. Rank, don't enumerate.
