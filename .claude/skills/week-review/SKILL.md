# Week Review

Run the weekly review. Work only from this vault.

1. Gather the last 7 days: `Daily-Briefs/` files, notes modified anywhere in the
   vault, tasks checked off in `Dashboard.md` and client notes.
2. Compare against the previous `week-review-*.md` if one exists.

Write `Daily-Briefs/week-review-YYYY-MM-DD.md` (today's date):

- **Shipped** — concrete outputs that left the building this week
- **Moved** — meaningful progress that didn't finish
- **Stalled** — what got zero touches, and whether it should be revived or killed
- **Numbers** — tasks completed vs added, notes created, clients touched,
  progress against the OS Config goal
- **Next week's focus** — max 3 themes, each with the first concrete action

Close with one honest paragraph: the week's grade (A–F) and the single biggest
leak to plug. No participation trophies.
