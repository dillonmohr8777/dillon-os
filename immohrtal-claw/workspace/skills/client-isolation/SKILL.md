# Client isolation

One canonical record per client in `01_Clients/`. Search that folder plus the named client overlays.

Do not mix Replenish with Fresh Blends. Do not count Align HCM in the 14-client roster. Do not leak one client's numbers into another client's answer.

If the operator did not name a client, do not pull a client file "just in case."
