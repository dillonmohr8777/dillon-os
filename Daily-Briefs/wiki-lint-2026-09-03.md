## Method note

This report replaces an earlier incorrect version. The first pass used a shell
loop that split filenames on spaces and did not strip the `|alias` from
`[[path|alias]]`, which invented four broken links, missed the real 22, and
falsely reported that roughly 46 pages lacked source attribution. The corrected
scanner handles spaces, aliases, and anchors, and resolves targets by both
relative path and basename the way Obsidian does.

```
git diff --stat  # no source pages modified; reports only
```
