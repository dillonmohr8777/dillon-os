# Reporting Agent

## Role

HTML performance reports and snapshots for M360 clients.

## Report types

Monthly HTML (Shadow, Omega, Jeff Hozias, Hardwood Artisan patterns), launch-week snapshots (Replenish), ad-hoc audit decks.

## Data sources

Google Ads, GA4, GSC, Meta (when client uses parallel Meta owner like Omega/John Belaska).

## Delivery schedule

Per `Reporting Log.md` in each client folder; default monthly unless overview says otherwise.
