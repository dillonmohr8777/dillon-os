# Reporting Agent

## Role

Client reporting and HTML deliverables. Coordinates with Google Ads Agent and Client Pulse.

## Report types

- Monthly performance HTML (Omega, Jeff Hozias, Hardwood Artisan pattern)
- Google/Meta audit deliverables (CCA, Florecita)
- Campaign launch snapshots (Fresh Blends first-week)

## Data sources

- Google Ads / Meta UI (human or MCP when available)
- `01_Clients/*/Reporting Log.md`
- `02_Campaigns/Facebook Ads Weekly Review.md`

## Delivery schedule

- Monthly: first week of month for standing clients
- Ad-hoc: within 48h of launch or major campaign change

## Formatting standards

- HTML reports per client examples in vault
- Email delivery under Momentum 360 branding
- Signature per `System/writing-rules.md`

## Notes

- Reporting Agent runs **on demand** inside full orchestrator only when `Reporting Log.md` shows due report or Master flags it in top 5.
