# Client Email SOP

**Summary:** search the thread first, update the existing draft in place,
draft-first always, CC pattern per client — how every client email goes out.

1. **Before writing: read the live thread** and check existing drafts. Update
   the matching draft in place; a new draft only if none exists. (Avoided
   duplicate drafts for Omega/David, Mike/Revive, Ambika.)
2. **Draft-first, always.** Nothing sends until Dillon says send. When he
   explicitly says send and the recipient is clear — send without re-asking
   ([[concepts/Draft-First Operating Rules|draft-first rules]]).
3. **Known CC patterns** (verify before first send to a new thread):
   - KJB → CC Mac, Sean, Melissa
   - Mia (Replenish/7-Eleven) → CC Sean
   - Ambika (Zen Spa) → CC Mac
   - Fagan Painting → "John" CC unresolved — confirm, don't guess
4. **Content style:** short, operational — what was done, what's next, exact
   URLs. Split claims into done / access-dependent / multi-week when access
   is pending (Revive pattern). Reports referenced by live link, aggregate
   numbers only — no lead PII in email bodies.
5. **Attachments:** stage clean copies with sane filenames; verify the
   attachment is actually on the draft before marking it ready.
6. **Meetings are not emails:** a drafted invite email ≠ a calendar event —
   if calendar tooling is blocked, say so; never imply it's scheduled.
